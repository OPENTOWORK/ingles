# Audio — Listening (B2 y otros)

Coloca aquí los ficheros de audio (`.mp3`, `.m4a`, `.wav`, `.ogg`). La app de práctica lee la **URL pública** que pegues en el campo `enunciado` de `levels_preguntas` en Supabase.

## URL en GitHub (rama `main`)

Tras hacer `git push`, la URL raw de un archivo en esta carpeta es:

```text
https://raw.githubusercontent.com/OPENTOWORK/ingles/main/listening-assets/b2/part-10/NOMBRE-DEL-ARCHIVO.mp3
```

Sustituye `NOMBRE-DEL-ARCHIVO.mp3` por el nombre real del fichero (sin espacios o usa `%20` en la URL).

## Convención sugerida

- `b2/part-10/` — Listening parte 10  
- `b2/part-11/` … `b2/part-13/` — resto de partes  

Puedes borrar los `.gitkeep` cuando añadas el primer audio en cada carpeta.
